# Voice Hub v4
تطوير فوق v3:
- حفظ دائم للمستخدمين والأرصدة والعمليات في data.json.
- سجل معاملات الهدايا.
- لوحة تحكم تجريبية على `/admin`.
- استمرار WebRTC/WebSocket والشات والهدايا.

## تشغيل
cd server
npm install
npm start

التطبيق: http://localhost:3000
لوحة الإدارة: http://localhost:3000/admin

هذه لوحة تجريبية بدون مصادقة إدارية حقيقية. قبل النشر العام يجب إضافة تسجيل دخول للمشرف، قاعدة بيانات حقيقية، HTTPS، TURN/SFU، وحدود وصلاحيات على الـAPI.
